# 和柏的回忆

蔡旆伦与柏君祥的静态情侣回忆网站，纪念日为 2026 年 5 月 11 日。

## 更新内容

编辑 `config.js`，修改昵称、纪念日、时间轴、相册和心愿。恋爱天数按北京时间的日期差计算，纪念日当天为 0 天。

相册清单在 `photo-library.js` 中维护。归档照片按文件夹显示为堆叠相册卡片，打开后支持左右切换和缩略图选片。根目录照片单独展示，`caption` 对应文件名配文。

`source` 保存原相对路径，用于识别文件夹归档。相册中的照片以相册名称和序号展示。添加独立照片时可使用 `album: "点滴回忆"`，添加归档照片时填写相应的相册名称。

添加照片时，先上传照片到 `images` 文件夹，再向 `window.PHOTO_LIBRARY` 数组添加内容。

```js
{ src: "./images/our-photo.jpg", caption: "照片的故事", album: "点滴回忆", date: "2026-05-11" },
```

向 `stories` 添加回忆。

```js
{ date: "2026-05-11", title: "回忆的标题", text: "想记下的话" },
```

向 `wishes` 添加心愿，完成后将 `done` 改为 `true`。

```js
{ text: "想一起做的事", done: false },
```

提交保存后，GitHub Pages 会自动更新。页面支持手机浏览，添加照片后可点击放大查看。

当前相册收录 `E:\照片` 外层照片与各归档相册，大连相册选用 `2026.10.1 大连\好看的`。照片以 WebP 网页浏览版本及缩略图发布。

「表白啦」聊天记录使用原始 JPEG 文件，清单中标记 `fullResolution: true`，可在弹窗中向下滚动阅读，也可通过「打开原图」单独放大查看。

「从相识到相恋」相册中的聊天记录也以原图发布，按文件顺序浏览。

## 部署

仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。

这是独立编写的静态实现。内容在仓库中维护，没有在线编辑后台。首页使用「初见」照片，文件为 `images/first-meeting.jpg`，可以通过替换该文件来更新首页照片。

页面、照片和仓库内容均公开可见。
